# 前端

Vue 3 + Vite，没用 UI 框架，样式都在 `src/style.css`。

## 跑起来

后端先起在 8000 端口：

```bash
cd ..
python server.py
```

再起前端：

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。开发服务器把 `/api` 代理到 `127.0.0.1:8000`。

## 两个页面

- **对话**：左侧选知识库，提问。回答下面的「引用」是这次命中的文档，点开看原文段落。
- **文档**：上传、删除文件，点「切分结果」看这个文件切成了哪几段。
- **设置**：右上角。改温度、检索方式、引用条数、阈值、重排开关，写的是 `data_dictionary` 表，保存即生效。

`?tab=docs` 直接打开文档页。

## 注意事项

- 对话记录按**用户**存，不按知识库分。切换知识库，历史还是同一份。
- 对话要求 `user` 表里有一条记录。库里没有用户时，页面左侧会提示插入语句。
- 打包用 `npm run build`，产物在 `dist/`，需要另配静态服务器或反向代理。
